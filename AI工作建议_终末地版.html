01
三方共识

核心瓶颈

不是工具不够多、能力不够强——而是创意判断力和执行劳动力长期捆绑在一起。

环节时间占比本质问题
UE5 还原阶段强创意 35% / 弱创意 40%把 AE 已确认的设计手工翻译成 UE5 节点
参考收集阶段强创意 10% / 弱创意 20%搜过的素材没有形成可检索资产
沟通对齐阶段弱创意 30% 调试修改第一版交付与需求方预期偏差，反复修改
LLM 提问阶段隐性，年约 42 小时每次对话都是独立会话，背景重新解释
绩效核心（网站首页 / PV / 抽卡 / 开宝箱 / 3D 综合方案）仅占工作内容的 30%，被上述执行劳动系统性侵蚀。
核心原则 A

AI 辅助执行，人保留判断。AI 是执行层放大器——放大已有方向和判断，不提供方向、不给出建议、不推荐选择。

核心原则 B

执行层标准化，创意层绝对自由。Bink 控件 / 参数卡 / 可行性清单是执行工具，不能预设任何视觉风格 / 节奏 / 内容。

01
Bink 最小闭环 · 跑通一个真实需求

结构性改变——把「手工翻译」工作流变成「投放播放」。强创意 UE5 还原时间砍掉 1/3 以上。四方共识最高优先级。

向程序员发的精准需求（直接复制发送）

「我需要在 UMG 里播放带 Alpha 的视频，方案是 ProRes4444 转 Bink。
你这边需要做：
① 确认 Bink 插件版本（UE5 已内置，无额外授权费）
② 封装 UMG Widget BP_BinkPlayer_Minimal，暴露参数：
   视频文件引用 / 自动播放 / 循环 / 播放速率 / 播放-暂停函数
   只做 Straight Alpha 混合 / Uniform Scale To Fill 缩放
我负责转码和测试资产。当前卡在哪个环节？」

设计师自备测试资产

  • AE 导出 5-10 秒动效，QuickTime + ProRes 4444（带 Alpha），1080p / 30fps / Straight Alpha / sRGB
  • 下载 RAD Video Tools（免费 GUI），转 Bink，勾选 Include Alpha，质量 80-85%，文件 < 50MB
  • 存 AE 导出预设，贴便签在显示器旁
  • 用「事后替换」：选已交付的线性播放动效，导出 Bink 替换原手工动画，对比效果

验收标准（不是"能播"就够）

  • Alpha 边缘干净（软边辉光素材测试）/ 色彩偏差可接受 / 首帧不闪 / 循环不跳
  • 重复打开关闭状态正常 / 有适用-不适用边界记录

常见阻力

  • 「要授权费」→ Bink 在 UE5 已包含，RAD Video Tools 编码器免费
  • 程序员排期紧 → 设计师先自行跑通转码流程
  • Alpha 有锯齿 → AE 导出选「直通 Alpha」而非预乘 Alpha
上限 2 个工作日 ROI 极高

03
Material 参数卡 · 第一批 5 张

启动成本极低，知识保质期极长（Material 节点原理不随 UE 版本变化）。6 个月后覆盖 80% 常用效果。

操作

  • 先在 3 个 Material 的 Description 注释框写关键词（10 秒/个）——最低成本起点
  • 项目收尾时花 30-60 分钟扩展成完整参数卡
  • 只存「预估复用概率高」的效果

每张卡字段

  • 效果名 + 截图 / 关键节点 / 可调参数名+范围 / 适用场景标签
  • 创作背景 / 意图——「为什么在这个场景选了这个值」，防止参数卡从辅助判断变成替代判断
  • 预估复用概率

优先做的前 3 个

  • 扫光（Fresnel / 方向光移动）
  • 溶解显隐（Noise 遮罩 + Alpha 渐变）
  • 径向扩散 / 遮罩推进

不重要 + 不紧急

明确放弃

这些要么低 ROI，要么容易变成新的时间黑洞。明确划线，不反复犹豫。

工具深度学习类
✕
UE5 Python 脚本系统化学习
无代码向 UI 动效设计师。学习成本极高，调试成本极高，不直接提升首页/PV/抽卡/3D Demo 质量。很多自动化未来被插件更新替代。
允许：让 LLM 临时生成小工具，但不系统学习。
✕
AE ExtendScript 深度学习
Adobe 正大力推进 Firefly AI 集成，ExtendScript 会被 Adobe 自身功能替代。容易从设计师变成工具维护员；报错和兼容问题会吞掉节省的时间。
允许：单个小脚本 1 小时内；只做批量命名、批量导出、资源清单、关键帧截图。
✕
ComfyUI 复杂节点流搭建
界面更新学习成本作废，工具迭代 3-6 个月内清零。正确位置是参考扩展（发现层），不是素材生成核心工具。
允许：用于项目内风格探索，不做工具研究。
AI 幻觉高风险类
✕
AI 从零生成复杂 Niagara 参数
LLM 对 Niagara 模块、参数、版本差异幻觉高。生成的参数组合大概率不能用，验证成本高于重新手调。等 Epic 官方推出更好的 Niagara AI 辅助工具。
允许：解释已有 Niagara / 整理参数 / 做排查 checklist / 改已有模板。
✕
自动 AE → UE 全链路转换
听起来很美，短期极难稳定。AE 表达系统和 UE5 实时系统差异太大，容易变成长期技术项目。
正确方向：半自动拆解；Bink 承接复杂视觉层；UMG/Material 承接实时交互层；AI 辅助生成清单和风险判断。
过度工程类
✕
大型个人知识库系统
容易沉迷工具、标签、数据库结构；维护成本高；会从「提效」变成「管理系统」。省出来的时间要回流到强创意，不是做展示。

工作流

三大整合型 Pipeline

强创意 / 弱创意 / 3D 综合方案，三条线各有专属流程。

STRONG · 强创意
Pipeline A · 视觉方向快速验证管道
适用：网站首页视觉方案、PV、重要付费环节。目标：「方向验证草稿」阶段从 2-3 天压缩到 4-6 小时。
1
风格语言激活 15 min
从风格语言文档提取 3 个风格关键词 + 2 个颜色指向 + 1 个运动感受词（要具体：不是「科技感」，而是「冷蓝 + 金属溢光 + 惯性缓动」）。生成 10-20 帧静帧方向图，锁定「光感和色彩结构对了」的参考帧。
2
关键帧提取 + 结构拆解 20 min
人工挑出 2-3 张「感觉对了」的帧（不可跳过，这是创意判断时刻）。用 Claude 把图像描述成 AE 可执行结构语言：「把这个画面拆解成 AE 层结构，告诉我需要哪些层类型、每层的运动轨迹、哪些效果适合 AE 原生插件完成。」
3
AE 草稿 + LLM 辅助 40-60 min
按 Step 2 结构起层。LLM 全程待命：① 表达式按需生成（遇到「这个表达式我要想一下」立即口述给 Claude，30 秒内得到可粘贴代码）；② 缓动效果按需生成（wiggle/elastic/bounce 等直接口述）。AI 处理执行，设计师负责所有节奏和视觉决策。
4
UE5 可行性预检 10 min（草稿 70% 时执行）
截图发给 LLM：「这个发光层是 AE Optical Flares，有大量半透明叠加层，UE5 UMG 中还原的主要瓶颈在哪？Bink 能完全绕过这个问题吗？」→ Bink 能解决则继续做 AE 准备导出；需要 UE5 原生制作则现在就启动规划。
5
Bink 导出 Bink 方案落地后启用
AE 渲染带 Alpha 序列帧 → RAD Video Tools 转 Bink（Include Alpha，质量 80-85%）→ 导入 UE5 Content/Videos/ → 拖入 BinkPlayer UMG 组件。AE 草稿即是可进 UE5 的资产，消除重复制作环节。
WEAK · 弱创意
Pipeline B · 规范化执行加速管道
适用：常规 UI 动效、标准转场、已有风格规范内的新需求。心智负担从「我要想怎么实现」降低到「我要确认怎么实现」。长期每周节省 5-8 小时。
1
需求分类 + LLM 预检 10 min
用 UE5 预检模板确认效果类型 / 推荐实现路径（Material/Animation/Bink/蓝图）/ 预估工时。拦截「在 UMG 里做 Niagara 实时粒子跟随」这类高成本方案，改为 Bink 播放。
2
材质参数卡检索 5 min
从材质卡库检索最近似模板，改参数而不是从零搭建。库累积到 30-40 张卡后，弱创意 UE5 制作阶段 80% 需求可直接调用。
3
UE5 制作 + LLM 顾问 按需
材质效果：口述需求给 LLM 得到节点清单，对照连线。蓝图逻辑：口述需求得到节点列表，照着拼接。LLM 给的节点名称在不同 UE5 版本有轻微差异，遇到找不到的节点先搜索近似名。
4
归档入库 15 min
成功的材质截图 + 参数描述 + 成功条件 → 材质卡库；成功的蓝图逻辑 → LLM 查询固化库；有效提示词 → 提示词资产库（按标签分类）。这是整个系统的「充电环节」。
3D · 综合方案
Pipeline C · 3D 综合方案风格锁定管道
适用：3D 概念综合大型方案（Blender + UE5）。解决「做了很久，评审时被说方向不对」。把方向偏移代价从三天白费降低到半天调整。
1
建视觉锚文档 30 min，每个大方案一次
用 Claude 结构化问答：「我正在设计 [游戏功能] 的 3D 视觉方案，风格参考词：[词1/词2/词3]。请帮我生成视觉锚文档，包含：色彩范围限定（主色/强调色/禁用色）、材质质感描述（金属感/透明度/粗糙度方向）、运动节奏描述（快慢分布/停顿感/冲击帧时长）、禁用元素清单。」
2
Blender + 生图双轨并行
Blender 做几何和灯光结构时，同步用生图工具做「同风格静帧参考」。不是用 AI 替代 Blender 建模，而是在建大型结构的同时，保持对「最终应该长什么样」的视觉锚。防止在 Blender 里花三天做了精细但方向偏了的东西。
3
风格一致性复核 每工作日 10 min
把当前进度截图发给 Claude，附上视觉锚文档：「对照这份视觉锚文档，当前截图里哪些元素已经偏离了？」Claude 做参数比对（「背景色温偏暖，与主色冷蓝有冲突」），不是创意判断而是标准检查。

效率工具

LLM 技术顾问标准化提问模板

存入本地文档，遇到对应场景直接复制填空，不要每次重新组织语言。

模板 01 · AE 表达式生成
我需要一个 After Effects 表达式，实现 [具体行为描述]，作用在 [图层属性名，如 Position/Opacity/Scale] 上，[输入条件]，[约束条件]。直接给我 ExtendScript 表达式代码，不需要解释。
模板 02 · UE5 蓝图逻辑咨询
在 UE5 UMG 中，我需要实现 [效果描述]，触发条件是 [事件/条件]。请列出需要的蓝图节点和连接逻辑，不需要详细解释，用步骤列表呈现。
模板 03 · 材质节点方案
UE5 Material Editor 中，实现 [效果名/描述] 需要哪些关键节点？请给出节点列表和主要参数设置，不需要写代码。已有节点：[如有]。
模板 04 · UE5 可行性预检
我计划把以下 AE 效果还原到 UE5 UMG 中：[效果描述+截图描述]。请评估：实现路径选择（Material/Animation/Bink/蓝图）、主要技术限制、预估实现难度（高/中/低）、有没有明显不可行的部分。
Material 效果 AI 半自动翻译 · 验证三步骤

选一个新 Material 效果，截图丢给 Claude → UE5 按清单连节点 → 走以下三步验证：

  • 极端值测试：把每个参数推到最大/最小，检查是否崩溃或意外结果
  • AB 对照参考：截图和目标参考对比，标出差异点
  • 逐个参数 ±30%：找「视觉锚点」——每个参数的「这个值以内都对，超过这个就过了」的边界

调参满意后存为 Material Function。同类型第二个以后 10 分钟内完成。

AI 暂时无法解决的边界
  • Niagara 粒子行为设计——LLM 幻觉成本高于帮助，等 Epic 原生工具
  • UE5 实时 Bug 调试（性能问题/运行时崩溃/平台兼容）——找程序员
  • 多职能说服力 Demo——仍需设计师主导，没有捷径
  • AE → UE5 自动桥接——Bink 是目前唯一可行方案
  • 创意方向判断——AI 可以快速具象化你描述的东西，但判断「这个方向好不好」必须是你做

如果只能做 3 件事

直接作用于绩效核心，不依赖任何组织配合，今天就能开始。

🥇 第一件事：Bink 极简控件 + 跑通一个真实需求（≤ 3 小时）

为什么是第一：它不是优化，是结构性改变——把「手工翻译」工作流变成「投放播放」。强创意 UE5 还原时间砍掉 1/3 以上。所有四方建议的共识最高优先级。

今天开始的动作

  • 打开 Claude，生成 BP_BinkPlayer_Minimal 蓝图节点列表（播放/停止/循环，只做 Straight Alpha 一种混合模式）

  • 存 AE 导出预设，贴便签在显示器旁

创意保护条款
Bink 控件永远只负责播放，不预设任何视觉风格 / 节奏 / 内容。封装层适配创意，创意不适应封装层。
🥈 第二件事：UE5 可行性速判清单建立 + 第一次使用（≤ 30 分钟）

为什么是第二：它防止你在「做不了」的方向上砸 70% 时间。止损的 ROI 永远高于提效。

今天开始的动作

  • 把三色清单（绿区/黄区/红区）存为 Claude Project 系统指令
  • 下次 AE 草稿做到 60-70% 时，截图丢给 Claude 速判（只判 3 个核心效果）
  • 前 5 次自己也过一遍，校正 AI 误判
铁律
永远不能在打开空白 AE 画布之前看它。清单只能回答技术可行性（能/不能/需绕路），不能提创意建议。
🥉 第三件事：Material 参数卡第一批 5 张（≤ 1 小时）

为什么是第三：伴随式建立的最强锚点。启动成本低，知识保质期极长，直接砍弱创意重复搭建时间。

今天开始的动作

  • 打开最近完成的项目，在 3 个 Material 的 Description 注释框写关键词（10 秒/个）
  • 项目收尾时花 30-60 分钟，把注释扩展成完整参数卡（含创作背景字段）
  • 只存「预估复用概率高」的效果
创意保护条款

不可妥协

核心底线

「系统不能做什么」的硬性约束，防止效率提升以创意自由为代价。

▲
AI 辅助执行，人保留判断
AI 是「执行层放大器」——放大已有方向和判断，不提供方向、不给出建议、不推荐选择。
▲
执行层标准化，创意层绝对自由
Bink 控件 / 参数卡 / 可行性清单是执行工具，不能预设任何视觉风格 / 节奏 / 内容。
▲
可行性预检的时机铁律
必须在草稿方向成型后使用，不能在打开 AE 前看清单；技术只判可行性，不提创意建议。
▲
AI 草稿素材用后即弃
正式设计阶段物理隔绝 AI 素材，重开空白 AE 工程凭记忆重建，防止 AI 生成物污染创意判断。
▲
任何模板不能包含「建议方案」或「推荐方向」
确认单是镜子（客观呈现分析），不是路牌（引导选择）。
▲
省下来的时间必须回流到强创意工作
决定绩效的是那 30%：网站首页 / PV / 抽卡 / 开宝箱 / 3D 综合方案。不能让省出的时间被更多弱创意需求填满。
草稿阶段 AI 介入分层协议
Type A · 沟通草稿（给他人看）

目的：让策划 / 主美 / PM 理解方向，推动决策。

AI 深度辅助：大量调用 AE 模板、LLM 生成常用表达式、脚本自动化重复操作（批量调参/导出规格）。

判断：这类草稿标准化合理，节省 30-40% 制作时间。

Type B · 探索草稿（给自己看）

目的：探索方向、验证直觉、突破预设。

保持 AE 完全自由，不做任何标准化。AI 的作用仅是「辅助执行已有想法」——「我知道要做什么但不知道怎么写」时按需咨询。

绝不用 AI 替代创意决策：节奏判断 / 缓动选择 / 停顿设计必须由设计师做。

最终警告

// 审计官最终警告

你最容易掉入的陷阱：把「工具探索」计入工作学习时间。


你的绩效和晋升由强创意工作的产出质量决定（30% 内容 / 50% 时长）。每当一个新 AI 工具出现，它会以「工作相关」为名消耗你的强创意时间，而 AI 工具给你带来真实 ROI 的场景非常具体（技术预检 / 风格锁定 / 参数文档化），单次收益不如「我用 AI 生成了一段很酷的视频」那么直观。


判断标准只有一个：这个工具能直接作用于网站首页 / PV / 3D 综合方案的交付质量吗？能的话投入，不能的话列入观察，6 个月后再看。

// 创意总监最终判断

你这个工种的天花板不由工具决定，由你对「什么是好的运动设计」的判断力决定。AI 把执行成本压低之后，你的判断力会被放大，而不是被稀释——前提是你没有把培养判断力的时间拿去学工具操作。

// GPT 最终总判断

你的优先级不应是「探索更多 AI 工具」，而是建立一套务实的生产飞轮：

强创意自由探索 → UE5 预检提前判断风险 → Bink 承接复杂视觉层
→ UMG / Material 承接交互和参数化层 → BUG 与有效方案轻量沉淀
→ 弱创意逐步标准化 → 释放更多时间给首页 / PV / 抽卡 / 3D Demo

你的长期竞争力不是「会用更多 AI 工具」，而是：有更强的动态视觉判断；能把强创意高保真落到 UE5；能用 AI 和标准化把低价值消耗压到最低；能把每次项目经验压缩成下一次可调用资产。
